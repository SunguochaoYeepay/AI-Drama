# AI Drama

面向新媒体内容生产的 AI 多角色剧情音频工程。

项目将把热点或原创故事拆解为角色台词、旁白、情绪与音效时间轴，并通过 MiniMax Speech 2.8 生成可用于后续视频制作的音频素材。

## 计划流程

1. 导入故事素材并进行原创化改编
2. 生成角色设定、分场脚本和配音参数
3. 调用 MiniMax 文本转语音接口生成分段音频
4. 合成对白、旁白、环境音和背景音乐
5. 导出完整音频、字幕与视频生成提示词

## 配置

本地密钥统一放在 `.env` 中。该文件不会提交到版本库。

```dotenv
MINIMAX_API_KEY=your_api_key
```
